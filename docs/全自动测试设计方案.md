## 使用方法

### 编译（需要在允许执行二进制的目录）

```bash
# 将项目复制到 Termux home 目录
cp -r /storage/emulated/0/ceshi/yumi ~/yumi
cd ~/yumi

# 编译 yumi-test
cargo build -p yumi-test
```

### 运行单元测试

```bash
cargo test
```

### 运行真机测试

```bash
# 运行所有测试
./target/debug/yumi-test run

# 只测某个模块
./target/debug/yumi-test run --module process
./target/debug/yumi-test run --module sysfs
./target/debug/yumi-test run --module fas

# 生成 HTML 报告
./target/debug/yumi-test run --report --output test_report/index.html

# 查看报告
termux-open test_report/index.html
```

### 列出所有测试模块

```bash
./target/debug/yumi-test list
```

## 测试模块说明

| 模块 | 测试内容 |
|------|----------|
| process | 检查 yumi 进程状态、PID 文件、内存占用、崩溃日志 |
| sysfs | 验证 CPU 频率节点、调频策略、cpuidle 节点 |
| fas | 检查 FAS 配置、帧率档位、日志事件 |
| clg | 检查 CLG 配置 |
| idle_dive | 检查空闲下潜配置 |
| touch | 检查触摸提频配置 |
| config | 读取和验证配置文件格式 |

## 注意事项

1. **环境限制**：Android 外部存储 (`/storage/emulated/0`) 不允许执行二进制文件，需要将项目复制到 Termux home 目录 (`~/`) 才能编译运行

2. **Root 权限**：部分 sysfs 测试可能需要 root 权限才能访问

3. **yumi 运行中**：process 和 fas 模块的测试需要 yumi 守护进程正在运行才能获得有意义的结果
